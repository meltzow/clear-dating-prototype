# CLEAR Dating Prototype

Focused product concept test for CLEAR.

## Current test: v2.2 reduced

The test intentionally checks one core hypothesis:

> In an unclear dating situation, does CLEAR help people become clearer about what they themselves want and what they want to do next?

Secondary signal: does the situation occupy them less mentally after the CLEAR flow?

## 10-screen flow

1. Dating preference for the example (women / men / either)
2. One unclear dating situation
3. BEFORE: clarity + mental load
4. CLEAR separates what is known from what is still open
5. The other person's part
6. The user's own needs
7. The user's own next action
8. AFTER: same clarity + mental-load questions
9. Real-world usage / substitute behavior
10. Open feedback

Not part of this test: matching, profiles, swiping, Reality Log, AI Coach, pricing, or Mel Robbins branding.

- Participant URL: GitHub Pages root
